# Desafio DIO — Classes de um Jogo

Projeto desenvolvido em Python como parte do desafio de lógica de programação da Digital Innovation One (DIO).

## Objetivo

Criar uma classe `Heroi` com os atributos nome, idade e tipo, além de um método `atacar()` que exibe uma mensagem de acordo com o tipo do personagem.

## Tecnologias utilizadas

- Python 3
- Programação Orientada a Objetos (POO)
- Estruturas condicionais (`if`, `elif` e `else`)

## Tipos de heróis e ataques

| Tipo | Ataque |
|---|---|
| Mago | Magia |
| Guerreiro | Espada |
| Monge | Artes marciais |
| Ninja | Shuriken |

## Como executar

1. Certifique-se de ter o Python instalado.
2. Abra um terminal na pasta do projeto.
3. Execute o comando:

```bash
python heroi.py
```

## Aprendizados

Prática de classes, objetos, construtores, métodos, atributos e estruturas condicionais em Python.
